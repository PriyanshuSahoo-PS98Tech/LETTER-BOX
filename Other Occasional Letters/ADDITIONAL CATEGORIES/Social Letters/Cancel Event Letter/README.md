# 📢 Cancel Event Letter

A professional, clear, and responsible event cancellation letter with animated envelope opening, formal notice effects, muted alert styling, and a refined cancellation notice presentation.

## 🏢 Overview

This interactive cancel event letter features a professional envelope-to-document experience designed to formally inform guests, participants, clients, staff, students, members, or stakeholders about the cancellation of an event. The template includes a calm notice-style animated background, refined formal document layout, subtle alert particles, professional typography, structured cancellation details, reason section, important updates section, apology statement, and a charcoal-red-amber theme perfect for cancelled functions, official events, meetings, seminars, workshops, school programs, college events, corporate gatherings, community events, and social functions.

## ✨ Features

- **Professional Envelope Animation**: Click to open a formal animated envelope and reveal the event cancellation letter
- **Notice Particle Effect**: Subtle alert-style particles appear when the cancellation notice is opened
- **Formal Notice Background**: Calm animated dots, alert symbols, and moving notice lines create an official update atmosphere
- **Refined Cancellation Layout**: Professional card-style presentation suitable for official cancellation communication
- **Structured Cancellation Details**: Dedicated section for event name, date, time, venue, reason, and status
- **Reason for Cancellation Section**: Formal area to clearly explain why the event has been cancelled
- **Important Updates Section**: Clearly presents refund, rescheduling, communication, and support-related updates
- **Apology Statement Section**: Respectfully acknowledges inconvenience and expresses regret
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for official cancellation notice submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the cancelled event name and date
   - Customize event name, original date, time, venue, cancellation reason, and current status
   - Update refund, rescheduling, registration, or support details as required
   - Replace contact information and attachment details as needed

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name, company, institution, or event organizer
   - Mention the exact event that has been cancelled
   - Keep the cancellation reason clear, brief, and professional
   - Add refund, ticket, registration, or rescheduling details if applicable
   - Mention official communication channels for future updates
   - Use a respectful and apologetic tone to maintain trust with recipients
   - Customize the tone depending on whether the cancellation is for a formal, academic, corporate, social, or community event

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
```

### Modifying Cancellation Subject

```text
Subject: Cancellation of [Event Name] Scheduled on [Event Date]
```

### Customizing Cancellation Details

```text
Event Name: [Mention Event Name]
Original Date: [Mention Scheduled Date]
Original Time: [Mention Scheduled Time]
Venue / Platform: [Mention Venue / Online Platform]
Reason: [Mention Brief Reason]
Current Status: Cancelled / Postponed Until Further Notice
```

### Updating Important Updates

```text
If the event is rescheduled, the revised date and venue will be shared soon.
If registration fees or tickets were collected, refund details will be communicated separately.
Guests and participants are requested to check official communication channels for updates.
For urgent queries, please contact the organizer using the details mentioned below.
We appreciate your patience, cooperation, and continued support.
```

### Updating Attachment Details

```text
Official cancellation notice
Refund or registration update, if applicable
Rescheduling information, if available
Contact details for queries or support
```
