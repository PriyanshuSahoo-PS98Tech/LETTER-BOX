# 🤍 Cancel Wedding Letter

A respectful, sensitive, and professional wedding cancellation letter with animated envelope opening, dignified soft-light effects, gentle falling-petal animations, and a refined formal notice presentation.

## 🏢 Overview

This interactive cancel wedding letter features a dignified envelope-to-document experience designed to formally inform guests, relatives, friends, families, and well-wishers about the cancellation of a wedding ceremony. The template includes a calm animated background, elegant formal notice layout, soft falling-light effects, gentle petal animations, professional typography, structured cancellation details, apology section, important notes section, and an ivory-rose-charcoal theme perfect for wedding cancellation notices, family announcements, guest communication, private ceremony updates, and respectful formal wedding-related correspondence.

## ✨ Features

- **Respectful Envelope Animation**: Click to open a dignified animated envelope and reveal the wedding cancellation letter
- **Soft Petal Notice Effect**: Gentle falling petal-style effects appear when the letter is opened
- **Calm Falling-Light Background**: Subtle vertical light animations create a sensitive and composed atmosphere
- **Refined Formal Notice Layout**: Professional card-style presentation suitable for private and formal wedding communication
- **Structured Cancellation Details**: Dedicated section for bride name, groom name, original date, venue, reason, and contact person
- **Apology and Understanding Section**: Formal area to express regret, inconvenience, and request for privacy
- **Important Notes Section**: Clearly presents travel, invitation, future update, contact, and privacy instructions
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical notice submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender name, family name, or representative information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the wedding cancellation notice
   - Customize bride name, groom name, original wedding date, venue, reason, and contact person details
   - Update apology wording and important notes according to the actual situation
   - Replace contact information and optional addition details as required

3. **Personalization Tips**:
   - Replace "Your Full Name / Family Name" with the actual sender or family representative name
   - Mention the bride and groom names only if appropriate for the notice
   - Keep the reason brief, respectful, and private if the matter is sensitive
   - Add a contact person for urgent guest queries
   - Include travel or accommodation guidance if guests had made arrangements
   - Mention future updates only if a postponement or new arrangement may be communicated later
   - Keep the tone calm, dignified, and sensitive throughout the letter
