# 💌 Decline Invitation Letter

A polite, graceful, and professional decline invitation letter with animated envelope opening, soft appreciation effects, elegant regret styling, and a refined formal response presentation.

## 🏢 Overview

This interactive decline invitation letter features a graceful envelope-to-document experience designed to politely refuse an invitation while maintaining respect, appreciation, and goodwill. The template includes a soft animated background, elegant formal card layout, gentle petal effects, professional typography, structured invitation response details, appreciation message section, reason for declining section, goodwill wishes section, and a plum-lavender-rose theme perfect for declining event invitations, function invitations, meeting invitations, ceremony invitations, party invitations, business invitations, social gatherings, and formal invitations with politeness and dignity.

## ✨ Features

- **Graceful Envelope Animation**: Click to open a polite animated envelope and reveal the decline invitation letter
- **Soft Petal Response Effect**: Gentle appreciation-style particles appear when the letter is opened
- **Elegant Formal Background**: Soft glowing orbs, light dots, and graceful motion lines create a respectful response atmosphere
- **Refined Response Card Layout**: Professional card-style presentation suitable for personal, social, and official invitation responses
- **Structured Invitation Response Details**: Dedicated section for event name, date, host, response, reason, and message type
- **Appreciation Message Section**: Formal area to express gratitude for being invited
- **Reason for Declining Section**: Polite explanation area for unavoidable circumstances
- **Good Wishes Section**: Clearly presents respectful wishes for the success of the event
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical response submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender name or organization information in the “From” section
   - Update recipient or host details in the “To” section
   - Modify the subject line according to the event or function name
   - Customize event name, event date, host name, reason, response details, and personal note
   - Update appreciation message and good wishes according to the invitation type
   - Replace contact information and optional addition details as required

3. **Personalization Tips**:
   - Replace "Your Full Name / Organization Name" with your actual name, family name, company, or institution
   - Mention the exact event or function invitation being declined
   - Keep the reason brief, honest, and respectful
   - Express appreciation before declining the invitation
   - Add warm wishes for the success of the event
   - Customize the tone depending on whether the invitation is personal, social, academic, cultural, or business-related
   - Avoid overly detailed personal reasons unless necessary
