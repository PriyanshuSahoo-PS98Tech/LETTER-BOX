# 💞 Invitation to Anniversary Party Letter

A joyful, elegant, and premium anniversary party invitation letter with animated envelope opening, romantic celebration effects, and a refined event-card presentation.

## 🏢 Overview

This interactive invitation to anniversary party letter features a luxurious envelope-to-invitation experience designed to make guests feel welcomed, valued, and excited to join a beautiful celebration of love and togetherness. The template includes a romantic animated background, elegant invitation card layout, premium typography, confetti celebration effects, floating hearts, and a rose-gold theme perfect for wedding anniversaries, family anniversary parties, milestone celebrations, silver jubilee anniversaries, golden jubilee anniversaries, and formal or personal anniversary invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the anniversary invitation letter
- **Joyful Confetti Celebration**: Beautiful confetti burst appears when the invitation is opened
- **Romantic Anniversary Styling**: Rose, blush, wine, and gold color theme for a warm celebration feel
- **Floating Heart Animation**: Soft rising hearts create a loving and joyful anniversary atmosphere
- **Premium Invitation Card Layout**: A refined card-style document designed for anniversary parties and celebrations
- **Festive Background Animation**: Floating orbs, sparkles, hearts, and animated ribbons create a happy celebration feel
- **Celebration Highlights Section**: Dedicated area for cake cutting, blessings, dinner, music, and photo moments
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for guest attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or family information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the anniversary party type
   - Customize anniversary year, couple name, date, time, venue, host, dress code, and RSVP details
   - Update celebration highlights according to the actual party schedule
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Family Name" with the actual host or family name
   - Mention the exact anniversary year such as 1st, 10th, 25th, or 50th anniversary
   - Add the couple’s name or host family name clearly
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better party planning
   - Mention dress code, dinner timing, entry pass, or special instructions if required
   - Customize the tone depending on whether the anniversary party is formal, family-based, romantic, grand, or intimate

```html
        <strong>Your Name / Family Name</strong><br>
        Your Address<br>

        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Address Line<br>
        City, State, PIN Code<br>
        Contact Details, if required
    </p>
</div>
```

```text

```
