# 🍽️ Invitation to Banquet Letter

A royal, elegant, and premium banquet invitation letter with animated envelope opening, golden celebration effects, and a refined hospitality-focused document presentation.

## 🏢 Overview

This interactive invitation to banquet letter features a luxurious envelope-to-document experience designed to invite respected guests to a formal banquet, dinner gathering, award dinner, farewell dinner, welcome banquet, annual celebration, business dinner, or special hospitality event. The template includes a rich animated background, elegant banquet card layout, premium typography, golden confetti effects, and a royal burgundy-gold theme perfect for formal dining invitations, official banquets, organizational dinners, family celebrations, ceremonial meals, and professional hospitality events.

## ✨ Features

- **Royal Envelope Animation**: Click to open a premium animated envelope and reveal the banquet invitation letter
- **Golden Confetti Celebration**: Elegant golden confetti appears when the banquet invitation is opened
- **Premium Banquet Card Layout**: A refined document-style presentation designed for formal dining events
- **Luxury Background Animation**: Floating orbs, sparkles, and golden ribbons create a grand banquet atmosphere
- **Hospitality-Focused Styling**: Professional design with warm, elegant, and welcoming banquet visuals
- **Banquet Details Section**: Dedicated area for banquet name, date, time, venue, host, and dress code
- **Evening Highlights Section**: Structured section for dinner arrangements, welcome, program flow, and guest interaction
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the banquet date or occasion
   - Customize banquet name, date, time, venue, host, dress code, and RSVP details
   - Update evening highlights according to the actual banquet program
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name or organization
   - Mention the exact banquet name or occasion clearly
   - Include complete venue or banquet hall details for easy guest navigation
   - Add RSVP date for proper seating and dining arrangements
   - Mention dress code if the banquet is formal, traditional, black tie, or themed
   - Customize the tone depending on whether the banquet is corporate, academic, ceremonial, family-based, or official

## 🛠️ Customization Guide

### Updating Sender Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Organization Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Designation / Organization Name<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Banquet Subject

```text
Subject: Invitation to Attend the Banquet on [Mention Date]
```

### Customizing Banquet Details

```text
Banquet Name: [Mention Banquet / Occasion Name]
Date: [Mention Date]
Time: [Mention Start Time]
Venue: [Mention Banquet Hall / Hotel / Location]
Host / Organizer: [Mention Host / Organization Name]
Dress Code: [Formal / Traditional / Black Tie / As Applicable]
```

### Updating Evening Highlights

```text
Warm welcome and guest reception
Formal opening and special address
Banquet dinner with hospitality arrangements
Guest interaction and memorable moments
Music, cultural segment, or special presentation, if applicable
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
