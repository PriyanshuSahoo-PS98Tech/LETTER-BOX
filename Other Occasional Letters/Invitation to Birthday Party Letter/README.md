# 🎂 Invitation to Birthday Party Letter

A joyful, colorful, and premium birthday party invitation letter with animated envelope opening, balloons, confetti effects, and a refined celebration-card presentation.

## 🏢 Overview

This interactive birthday party invitation letter features a cheerful envelope-to-invitation experience designed to make guests feel excited, welcomed, and happy. The template includes floating balloons, sparkling party elements, animated streamers, a premium birthday card layout, colorful confetti celebration effects, and a vibrant purple-pink-gold theme perfect for birthday party invitations, family celebrations, children's birthday parties, friends' birthday gatherings, milestone birthdays, and formal birthday invitation letters.

## ✨ Features

- **Joyful Envelope Animation**: Click to open a colorful animated envelope and reveal the birthday invitation letter
- **Birthday Confetti Celebration**: Bright confetti burst appears when the invitation is opened
- **Floating Balloon Background**: Animated balloons create a happy and festive birthday atmosphere
- **Premium Birthday Card Layout**: A refined card-style document designed for birthday party invitations
- **Party Streamer Animation**: Moving decorative streamers add celebration energy to the background
- **Floating Decorative Icons**: Birthday cake, balloons, gifts, sparkles, and party symbols enhance the design
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical birthday invitation submission
- **RSVP Section**: Dedicated confirmation area for guest attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or family information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the birthday person’s name
   - Customize birthday person name, age, date, time, venue, theme, and RSVP details
   - Update party highlights according to the actual birthday program
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Family Name" with your actual name or family name
   - Mention the exact birthday person’s name
   - Add the birthday age if the invitation requires it
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better party planning
   - Mention theme, dress code, games, food arrangements, or special instructions if required
   - Customize the tone depending on whether the party is for a child, friend, family member, colleague, or formal guest

## 🛠️ Customization Guide

### Updating Sender Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Family Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Dear Friend / Guest Name</strong><br>
        Address Line<br>
        City, State, PIN Code<br>
        Contact Details, if required
    </p>
</div>
```

### Modifying Birthday Invitation Subject

```text
Subject: Invitation to Birthday Party of [Birthday Person's Name]
```

### Customizing Birthday Party Details

```text
Birthday Person: [Mention Birthday Person's Name]
Birthday Age: [Mention Age, if required]
Date: [Mention Party Date]
Time: [Mention Start Time]
Venue: [Mention Venue / Home / Hall / Restaurant]
Theme / Dress Code: [Mention Theme or Dress Code, if any]
```

### Updating Party Highlights

```text
Cake cutting ceremony with family and friends
Fun games, music, dance, and cheerful activities
Birthday wishes, blessings, and memorable photos
Delicious snacks, refreshments, and dinner arrangements
Return gifts or special surprises, if planned
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
