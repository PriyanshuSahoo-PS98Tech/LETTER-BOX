# ☕ Invitation to Brunch Letter

A warm, elegant, and joyful brunch invitation letter with animated envelope opening, sunny café-style visuals, soft floating food elements, and a refined invitation-card presentation.

## 🏢 Overview

This interactive invitation to brunch letter features a cheerful envelope-to-invitation experience designed to make the recipient feel warmly welcomed and excited to attend. The template includes a sunny brunch-themed animated background, elegant café-style invitation card layout, premium typography, soft petal effects, warm food-inspired visuals, and a caramel-gold-cream theme perfect for brunch gatherings, family brunches, friend meetups, weekend brunches, office brunch invitations, casual celebrations, and social get-togethers.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium brunch-themed envelope and reveal the invitation letter
- **Warm Petal Celebration**: Soft falling petal effects appear when the invitation is opened
- **Premium Brunch Card Layout**: A refined card-style document designed for cozy and cheerful gatherings
- **Sunny Café Background Animation**: Floating orbs, steam effects, and brunch icons create a warm morning atmosphere
- **Food-Inspired Visual Styling**: Coffee, croissant, pancakes, strawberry, honey, and herb visuals enhance the brunch feel
- **Floating Decorative Icons**: Soft brunch symbols add warmth and personality to the invitation experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for brunch attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the brunch date or occasion
   - Customize brunch occasion, date, time, venue, host, dress code, and RSVP details
   - Update brunch highlights according to the actual menu or gathering plan
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with your actual name or host name
   - Update contact information with correct phone number and email address
   - Mention the exact brunch occasion or gathering purpose
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better food and seating arrangements
   - Mention dietary notes, menu highlights, dress code, or special instructions if required
   - Customize the tone depending on whether the brunch is casual, family-based, corporate, celebratory, or friendly

## 🛠️ Customization Guide

### Updating Host Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Host Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Dear Guest / Recipient Name</strong><br>
        Address Line<br>
        City, State, PIN Code<br>
        Contact Details, if required
    </p>
</div>
```

### Modifying Brunch Invitation Subject

```text
Subject: Invitation to Join Us for Brunch on [Mention Date]
```

### Customizing Brunch Details

```text
Occasion: [Mention Brunch Occasion / Casual Gathering]
Date: [Mention Date]
Time: [Mention Brunch Time]
Venue: [Mention Home / Restaurant / Café / Location]
Hosted By: [Mention Host Name]
Dress Code: [Casual / Smart Casual / Theme, if any]
```

### Updating Brunch Highlights

```text
Warm welcome with tea, coffee, juice, or refreshing drinks
Delicious brunch menu with light bites, snacks, and sweet treats
Relaxed conversations and quality time with friends or family
Cozy atmosphere for laughter, photos, and memorable moments
Special arrangements for guests, if required
```

### Updating RSVP Details

```text
Please confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
