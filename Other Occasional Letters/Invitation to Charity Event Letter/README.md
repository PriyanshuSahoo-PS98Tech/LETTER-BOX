# 💚 Invitation to Charity Event Letter

A compassionate, elegant, and premium charity event invitation letter with animated envelope opening, heartfelt visual effects, and a refined charity-focused document presentation.

## 🏢 Overview

This interactive invitation to charity event letter features a warm envelope-to-document experience designed to invite guests, donors, volunteers, supporters, and well-wishers to a meaningful charitable event. The template includes a compassionate animated background, elegant charity card layout, premium typography, soft blessing effects, and a green-gold theme perfect for fundraising events, donation drives, social service programs, NGO events, welfare functions, awareness campaigns, community support events, and formal charity invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the charity invitation letter
- **Compassionate Blessing Effects**: Soft floating hearts, hands, leaves, and hope symbols appear when the invitation is opened
- **Premium Charity Card Layout**: A refined card-style document designed for meaningful charity and social service events
- **Warm Background Animation**: Floating orbs, heart icons, and animated ribbons create a hopeful and caring atmosphere
- **Cause-Focused Event Styling**: Professional design with a compassionate charity invitation tone
- **Purpose of the Event Section**: Dedicated area to explain the cause, mission, and beneficiaries
- **Support Impact Section**: Clearly communicates how the guest’s presence or contribution can help
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP and Donation Contact Section**: Dedicated confirmation area for attendance, donation, or volunteer registration
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the charity event name
   - Customize charity event name, date, time, venue, cause, and contribution details
   - Update the purpose of the event according to the actual charity mission
   - Replace RSVP, donation, volunteer registration, and contact details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name, NGO, trust, school, company, or organization
   - Mention the exact charity event or fundraising program being organized
   - Clearly describe the cause, beneficiaries, and expected impact
   - Include complete venue details for easy guest navigation
   - Add donation options, volunteer registration details, or contribution instructions if required
   - Mention whether guests can contribute through funds, food, clothes, books, medical aid, or volunteering
   - Customize the tone depending on whether the event is formal, community-based, NGO-led, school-led, corporate, or personal
