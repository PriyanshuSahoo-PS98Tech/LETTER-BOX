# 🥂 Invitation to Cocktail Party Letter

A stylish, elegant, and premium cocktail party invitation letter with animated envelope opening, golden celebration effects, and a refined evening-event presentation.

## 🏢 Overview

This interactive invitation to cocktail party letter features a luxurious envelope-to-invitation experience designed to make the recipient feel welcomed, valued, and excited for an elegant evening gathering. The template includes a premium animated background, lounge-style invitation card layout, refined typography, golden confetti effects, and a midnight-plum-gold theme perfect for cocktail parties, evening celebrations, office social events, private gatherings, formal receptions, anniversary evenings, networking parties, and premium social invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the cocktail party invitation
- **Golden Confetti Celebration**: Beautiful golden and rose-toned confetti appears when the invitation is opened
- **Premium Evening Card Layout**: A refined card-style document designed for stylish evening gatherings
- **Luxury Lounge Background Animation**: Floating bokeh lights, sparkles, and golden line effects create a classy party atmosphere
- **Midnight Cocktail Styling**: Professional design with a warm, elegant, and sophisticated invitation feel
- **Floating Decorative Icons**: Soft cocktail, music, sparkle, and celebration symbols enhance the experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for guest attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host information in the “From” section
   - Update guest details in the “To” section
   - Modify the subject line according to the cocktail party date or occasion
   - Customize occasion, date, time, venue, host name, and dress code
   - Update evening highlights according to the actual party plan
   - Replace contact information, RSVP date, and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with the actual host or organization name
   - Update contact information with the correct phone number and email address
   - Mention the exact occasion or celebration for the cocktail party
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better hospitality and seating arrangements
   - Mention dress code such as formal, semi-formal, cocktail attire, or themed attire
   - Add entry pass, guest count, timing, or venue-specific guidelines if required

## 🛠️ Customization Guide

### Updating Host Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Host Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Guest Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Designation / Organization Name<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Cocktail Party Subject

```text
Subject: Invitation to Attend Cocktail Party on [Mention Date]
```

### Customizing Cocktail Party Details

```text
Occasion: [Mention Occasion / Celebration]
Date: [Mention Party Date]
Time: [Mention Start Time]
Venue: [Mention Venue / Lounge / Banquet / Address]
Hosted By: [Mention Host Name]
Dress Code: [Formal / Semi-formal / Cocktail Attire]
```

### Updating Evening Highlights

```text
Warm welcome and guest interaction
Elegant cocktail-style refreshments and hospitality
Music, lounge ambiance, and relaxed conversations
Celebration toast or short address, if applicable
Dinner, snacks, or special serving arrangements as planned
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
