# 🍽️ Invitation to Dinner Party Letter

A warm, elegant, and premium dinner party invitation letter with animated envelope opening, candlelight ambience, celebratory confetti effects, and a refined invitation-card presentation.

## 🏢 Overview

This interactive invitation to dinner party letter features a luxurious envelope-to-invitation experience designed to make the recipient feel warmly welcomed and personally valued. The template includes a candlelight-inspired animated background, elegant dinner invitation card layout, premium typography, soft celebratory effects, and a wine-gold-champagne theme perfect for family dinners, formal dinner parties, friendly gatherings, office dinners, celebration dinners, anniversary dinners, festive dinners, and special evening invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the dinner invitation letter
- **Warm Confetti Celebration**: Beautiful confetti burst appears when the invitation is opened
- **Premium Dinner Invitation Card Layout**: A refined card-style document designed for graceful dinner invitations
- **Candlelight Background Animation**: Flickering lights, glowing orbs, and soft steam effects create a warm dining atmosphere
- **Royal Dinner Party Styling**: Professional design with a cozy, classy, and joyful evening theme
- **Floating Decorative Icons**: Soft dinner, candle, toast, dessert, and sparkle symbols enhance the invitation experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for dinner attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the dinner party date or occasion
   - Customize dinner occasion, date, time, venue, host name, and dress code
   - Update evening highlights according to the actual dinner plan
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with your actual name or host name
   - Mention the exact dinner party occasion or celebration
   - Include complete venue or home address for easy guest navigation
   - Add RSVP date for better dinner arrangements
   - Mention dress code, menu details, guest instructions, or arrival time if required
   - Customize the tone depending on whether the dinner party is formal, family-based, friendly, corporate, festive, or romantic

## 🛠️ Customization Guide

### Updating Host Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Host Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Address Line<br>
        City, State, PIN Code<br>
        Contact Details, if required
    </p>
</div>
```

### Modifying Dinner Invitation Subject

```text
Subject: Invitation to Dinner Party on [Mention Date]
```

### Customizing Dinner Party Details

```text
Occasion: [Mention Occasion / Dinner Party Name]
Date: [Mention Dinner Date]
Time: [Mention Dinner Time]
Venue: [Mention Complete Venue / Address]
Hosted By: [Mention Host Name / Family Name]
Dress Code: [Mention Dress Code, if any]
```

### Updating Evening Highlights

```text
Warm welcome and friendly gathering
Delicious dinner and refreshments
Music, conversations, and joyful moments
Family, friends, and guest interaction
Memorable photos and celebration memories
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
