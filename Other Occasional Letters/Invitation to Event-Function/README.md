# 🎉 Invitation to Event/Function Letter

A joyful, elegant, and premium invitation letter with animated envelope opening, celebratory confetti effects, and a refined event-card presentation.

## 🏢 Overview

This interactive invitation letter features a luxurious envelope-to-invitation experience designed to make the recipient feel welcomed, valued, and happy. The template includes a festive animated background, elegant invitation card layout, premium typography, confetti celebration effects, and a royal purple-gold-rose theme perfect for event invitations, functions, ceremonies, cultural programs, school events, college functions, office gatherings, family celebrations, and formal social invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the invitation letter
- **Joyful Confetti Celebration**: Beautiful confetti burst appears when the invitation is opened
- **Premium Invitation Card Layout**: A refined card-style document designed for formal and festive events
- **Festive Background Animation**: Floating orbs, sparkles, and animated ribbons create a happy celebration feel
- **Royal Event Styling**: Professional design with a warm and joyful invitation atmosphere
- **Floating Decorative Icons**: Soft celebration symbols enhance the invitation experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for event attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the event or function name
   - Customize event name, date, time, venue, host, dress code, and RSVP details
   - Update program highlights according to the actual event schedule
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name or organization
   - Update contact information with correct phone number and email address
   - Mention the exact event or function being organized
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better event planning
   - Mention dress code, entry pass, program schedule, or special instructions if required
   - Customize the tone depending on whether the event is formal, cultural, family-based, academic, or corporate

## 🛠️ Customization Guide

### Updating Sender Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Organization Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Designation / Organization Name<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Invitation Subject

```text
Subject: Invitation to Attend [Event / Function Name]
```

### Customizing Event Details

```text
Event Name: [Mention Event / Function Name]
Date: [Mention Event Date]
Time: [Mention Start Time]
Venue: [Mention Venue / Hall / Location]
Host / Chief Guest: [Mention Name, if applicable]
Dress Code: [Mention Dress Code, if any]
```

### Updating Program Highlights

```text
Warm welcome and opening address
Formal ceremony or event proceedings
Cultural / celebration / activity segment
Guest interaction and memorable moments
Refreshments, dinner, or hospitality arrangements
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```

Print styles automatically optimize the layout for professional invitation submission.
