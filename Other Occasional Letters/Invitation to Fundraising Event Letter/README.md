# 🤝 Invitation to Fundraising Event Letter

A warm, elegant, and professional fundraising event invitation letter with animated envelope opening, meaningful giving-themed effects, and a refined event-card presentation.

## 🏢 Overview

This interactive invitation to fundraising event letter features a compassionate envelope-to-letter experience designed to invite donors, guests, supporters, community members, sponsors, and well-wishers to a fundraising event. The template includes a warm animated background, elegant fundraising invitation card layout, premium typography, giving-themed floating effects, structured event details, contribution information, and an emerald-gold theme perfect for charity events, donation drives, NGO fundraisers, school fundraising programs, community welfare events, medical aid fundraisers, social campaigns, and sponsorship-based events.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the fundraising invitation letter
- **Giving-Themed Visual Effects**: Floating gratitude icons such as hearts, hands, leaves, and support symbols
- **Premium Fundraising Card Layout**: A refined card-style document designed for formal and meaningful fundraising communication
- **Warm Background Animation**: Floating orbs, sparkles, and soft leaf movement create a hopeful and compassionate feel
- **Cause-Focused Event Styling**: Professional design with a trustworthy, generous, and emotionally warm atmosphere
- **Structured Contribution Details**: Dedicated section for donation amount, payment mode, receipts, and sponsorship information
- **Purpose of Fundraising Section**: Clearly explains the goal, cause, beneficiary, and impact of the event
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for attendance, donation details, and sponsorship queries
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update donor, guest, sponsor, or recipient details in the “To” section
   - Modify the subject line according to the fundraising cause or event name
   - Customize event name, cause, date, time, venue, fundraising goal, and RSVP details
   - Update purpose points according to the actual cause or beneficiary
   - Add donation mode, payment details, receipt information, and sponsorship details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with the actual organizer or organization name
   - Mention the exact cause, beneficiary, project, or campaign being supported
   - Include the fundraising goal amount if it is publicly shareable
   - Add transparent contribution details such as payment mode, receipt availability, or sponsorship options
   - Keep the message warm, respectful, and trustworthy
   - Customize the tone depending on whether the event is charity-based, NGO-based, school-based, community-based, corporate, or personal-cause related
