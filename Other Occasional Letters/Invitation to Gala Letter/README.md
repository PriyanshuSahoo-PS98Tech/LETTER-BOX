# 🥂 Invitation to Gala Letter

A luxurious, elegant, and premium gala invitation letter with animated black-gold envelope opening, refined celebration effects, and a formal gala-card presentation.

## 🏢 Overview

This interactive invitation to gala letter features a premium envelope-to-invitation experience designed to make the recipient feel honored, respected, and warmly welcomed to a distinguished evening. The template includes a luxury black-gold animated background, elegant gala card layout, formal typography, golden confetti effects, and a sophisticated champagne-gold theme perfect for charity galas, award nights, annual galas, corporate gala dinners, fundraising events, cultural galas, formal ceremonies, and prestigious social gatherings.

## ✨ Features

- **Luxury Envelope Animation**: Click to open a premium black-gold animated envelope and reveal the gala invitation letter
- **Golden Confetti Celebration**: Elegant golden confetti burst appears when the invitation is opened
- **Premium Gala Card Layout**: A refined formal card-style document designed for prestigious events
- **Luxury Background Animation**: Floating golden orbs, sparkles, and light beams create a grand evening atmosphere
- **Black-Gold Gala Styling**: Professional and royal design suitable for high-class formal occasions
- **Floating Decorative Icons**: Soft gala symbols enhance the elegant invitation experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for guest attendance and arrangements
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the gala name or gala evening title
   - Customize gala name, date, time, venue, host, chief guest, dress code, and RSVP details
   - Update evening highlights according to the actual gala program
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name or organization
   - Update contact information with correct phone number and email address
   - Mention the exact gala name or formal evening title
   - Include complete venue details such as hotel, ballroom, banquet hall, or auditorium
   - Add RSVP date for proper seating and hospitality arrangements
   - Mention black tie, formal, traditional, or custom dress code if required
   - Customize the tone depending on whether the gala is corporate, charity-based, cultural, academic, or social

```html
    <p>
        <strong>Your Name / Organization Name</strong><br>

        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Honorable Invitee</strong><br>
        Designation / Organization Name<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Gala Subject

```text
Subject: Invitation to Attend [Gala Name / Gala Evening]
```

### Customizing Gala Details

```text
Gala Name: [Mention Gala Name]
Date: [Mention Gala Date]
Time: [Mention Start Time]
Venue: [Mention Venue / Ballroom / Hotel / Hall]
Host / Chief Guest: [Mention Name, if applicable]
Dress Code: [Black Tie / Formal / Traditional / Mention Dress Code]
```

### Updating Evening Highlights

```text
Welcome reception and guest registration

Awards, recognition, or appreciation segment
Cultural performance / entertainment program
Dinner, networking, and hospitality arrangements
```

### Updating RSVP Details

```text

Contact: [Phone Number]
Email: [Email Address]
```
