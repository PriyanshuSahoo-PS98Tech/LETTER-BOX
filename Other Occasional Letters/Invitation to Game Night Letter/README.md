# 🎮 Invitation to Game Night Letter

A fun, energetic, and premium game night invitation letter with animated envelope opening, arcade-style visuals, playful confetti effects, and a refined event-card presentation.

## 🏢 Overview

This interactive invitation to game night letter features a lively envelope-to-invitation experience designed to make guests feel excited, welcomed, and ready for a fun evening. The template includes a neon arcade-inspired animated background, elegant game-themed card layout, premium typography, game-symbol confetti effects, and a vibrant cyan-purple-pink theme perfect for friendly game nights, family game evenings, office game events, college fun nights, online gaming parties, board game gatherings, and casual social invitations.

## ✨ Features

- **Animated Envelope Opening**: Click to open a premium game-themed envelope and reveal the invitation letter
- **Arcade-Style Game Theme**: Neon-inspired design with game symbols, glowing elements, and playful visual details
- **Game Confetti Celebration**: Game icons and colorful confetti appear when the invitation is opened
- **Premium Invitation Card Layout**: A refined card-style document designed for both casual and semi-formal game night invitations
- **Animated Background Effects**: Floating game symbols, neon lines, and glowing orbs create a fun party atmosphere
- **Game Night Details Section**: Dedicated section for date, time, venue, host, theme, and dress code
- **Games & Fun Activities Section**: Highlights games, competitions, snacks, prizes, and entertainment
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host or organizer information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the game night name or theme
   - Customize game night date, time, venue, host, dress code, and RSVP details
   - Update games and activities according to the planned event
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with your actual name or organizer name
   - Update contact information with correct phone number and email address
   - Mention the exact game night date, time, and venue
   - Add whether the event is offline, online, family-based, friends-only, office-based, or college-based
   - Mention games such as board games, card games, video games, quizzes, puzzles, or team challenges
   - Include RSVP date for better planning of teams, snacks, seating, and game arrangements
   - Customize the tone depending on whether the game night is casual, friendly, family-oriented, or professional
