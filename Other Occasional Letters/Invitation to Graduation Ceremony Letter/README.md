# 🎓 Invitation to Graduation Ceremony Letter

A prestigious, elegant, and premium graduation ceremony invitation letter with animated envelope opening, academic celebration effects, and a refined ceremonial document presentation.

## 🏢 Overview

This interactive graduation ceremony invitation letter features a luxurious envelope-to-document experience designed to invite guests, parents, faculty members, dignitaries, and well-wishers to a formal graduation or convocation ceremony. The template includes a premium academic background, elegant ceremony card layout, professional typography, celebratory confetti effects, and a navy-blue-gold theme perfect for graduation ceremonies, convocations, award ceremonies, certificate distribution functions, school graduations, college graduations, university ceremonies, and formal academic events.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium academic envelope and reveal the graduation invitation letter
- **Graduation Confetti Celebration**: Beautiful navy, gold, and white confetti burst appears when the invitation is opened
- **Premium Ceremony Card Layout**: A refined document-style card designed for formal academic invitations
- **Academic Background Animation**: Floating orbs, glowing stars, and animated ribbons create a prestigious ceremony feel
- **Royal Graduation Styling**: Professional navy-blue-gold design with an academic celebration atmosphere
- **Floating Decorative Icons**: Graduation caps, medals, certificates, stars, and celebration symbols enhance the experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical graduation invitation submission
- **RSVP Section**: Dedicated confirmation area for guest attendance and seating arrangements
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace institution, department, or organizer information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the graduation or convocation ceremony
   - Customize ceremony name, date, time, venue, chief guest, dress code, and RSVP details
   - Update program highlights according to the actual graduation ceremony schedule
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Institution Name" with your actual institution or organizer name
   - Update contact information with correct phone number and email address
   - Mention the exact graduation ceremony, convocation, or certificate distribution event
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better seating and hospitality planning
   - Mention dress code, entry pass, academic robe instructions, program schedule, or special guest details if required
   - Customize the tone depending on whether the ceremony is for school, college, university, institute, or training program

### Updating Sender Information

```html
    <p>
        <strong>Your Name / Institution Name</strong><br>
        Department / School / College Name<br>
        Institution Address<br>
        Email: graduation@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Designation / Organization Name<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Graduation Subject

```text
Subject: Invitation to Attend the Graduation Ceremony
```

### Customizing Ceremony Details

```text
Ceremony Name: [Graduation Ceremony / Convocation Name]
Date: [Mention Ceremony Date]
Time: [Mention Start Time]
Venue: [Mention Auditorium / Hall / Campus Location]
Chief Guest: [Mention Chief Guest Name, if applicable]
Dress Code: [Formal / Academic Robe / Traditional, if applicable]
```

### Updating Program Highlights

```text
Welcome address and ceremonial opening
Academic procession and lamp lighting, if applicable
Address by the chief guest and dignitaries
Awarding of certificates, degrees, or honors
Student recognition and achievement celebration
Vote of thanks, group photographs, and refreshments
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
