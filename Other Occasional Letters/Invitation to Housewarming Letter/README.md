# 🏠 Invitation to Housewarming Letter

A warm, elegant, and premium housewarming invitation letter with animated envelope opening, blessing-inspired festive effects, and a refined home-celebration presentation.

## 🏢 Overview

This interactive invitation to housewarming letter features a beautiful envelope-to-invitation experience designed to make guests feel warmly welcomed to a new home celebration. The template includes a festive animated background, elegant invitation card layout, premium typography, blessing-inspired floating effects, and a warm maroon-gold-terracotta theme perfect for housewarming ceremonies, Griha Pravesh invitations, new home celebrations, family gatherings, traditional rituals, and formal home blessing invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the housewarming invitation letter
- **Blessing-Inspired Celebration Effects**: Floating diyas, flowers, sparkles, and home-themed icons create a warm festive experience
- **Premium Housewarming Card Layout**: A refined card-style document designed for traditional and modern housewarming invitations
- **Warm Festive Background Animation**: Floating orbs, diyas, garlands, and soft glowing elements create a joyful home celebration feel
- **Traditional Yet Professional Styling**: Suitable for family, social, cultural, and formal housewarming invitations
- **Housewarming Details Section**: Dedicated area for ceremony date, time, venue, host, and meal details
- **Ceremony Highlights Section**: Structured section for rituals, blessings, hospitality, and celebration details
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or family information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the ceremony name
   - Customize ceremony date, time, venue, host, meal timing, and RSVP details
   - Update ceremony highlights according to the actual rituals or program schedule
   - Replace contact information, new home address, and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Family Name" with your actual name or family name
   - Mention whether the occasion is Housewarming Ceremony, Griha Pravesh, or New Home Celebration
   - Include complete new home address and location details for easy guest navigation
   - Add lunch, dinner, or refreshment timing if applicable
   - Mention RSVP date for better hospitality planning
   - Customize the tone depending on whether the ceremony is traditional, modern, religious, family-based, or formal

