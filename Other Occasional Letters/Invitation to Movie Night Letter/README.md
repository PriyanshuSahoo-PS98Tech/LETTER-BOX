# 🎬 Invitation to Movie Night Letter

A fun, cinematic, and premium invitation letter with animated envelope opening, theater-style background effects, popcorn confetti, and a refined movie-ticket card presentation.

## 🏢 Overview

This interactive invitation to movie night letter features a stylish cinema-themed envelope-to-invitation experience designed to make the recipient feel excited, welcomed, and ready for a cozy entertainment evening. The template includes animated spotlights, film-strip effects, glowing stars, floating popcorn elements, ticket-style document styling, premium typography, and a warm red-gold cinema theme perfect for friendly movie nights, family movie gatherings, college movie evenings, office movie events, club screenings, hostel movie nights, and casual entertainment invitations.

## ✨ Features

- **Cinematic Envelope Animation**: Click to open a premium animated envelope and reveal the movie night invitation
- **Movie-Theater Background**: Animated spotlights, film strips, stars, and popcorn elements create a cinema atmosphere
- **Popcorn and Ticket Confetti**: Fun celebration effects appear when the invitation is opened
- **Premium Ticket-Card Layout**: A refined document design inspired by movie tickets and theater passes
- **Warm Friendly Letter Tone**: Invitation content designed for friends, family, guests, or group members
- **Movie Night Details Section**: Dedicated area for date, time, venue, movie/theme, and dress code
- **What to Expect Section**: Highlights snacks, refreshments, comfort, conversations, and activities
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation sharing
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host information in the “From” section
   - Update guest details in the “To” section
   - Modify the subject line according to your movie night invitation
   - Customize movie night date, time, venue, movie name, genre, theme, and dress code
   - Update snacks, activities, RSVP date, contact number, and email address
   - Replace notes or attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with your actual name
   - Mention the exact movie night date and start time
   - Add the movie name, genre, or theme if already decided
   - Include whether guests should bring snacks, drinks, cushions, blankets, or movie suggestions
   - Mention whether it is a friends-only, family, college, office, or community movie night
   - Customize the tone depending on whether the invitation is casual, friendly, family-based, or group-based
