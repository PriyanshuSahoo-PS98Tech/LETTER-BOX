# 🌹 Invitation to Reception Letter

A joyful, elegant, and premium reception invitation letter with animated envelope opening, ceremonial petals, celebratory confetti effects, and a refined reception-card presentation.

## 🏢 Overview

This interactive invitation to reception letter features a luxurious envelope-to-invitation experience designed to make guests feel welcomed, respected, and honored. The template includes a ceremonial animated background, elegant reception card layout, premium typography, falling petal effects, confetti celebration effects, and a royal maroon-gold-rose theme perfect for wedding receptions, family receptions, formal ceremonies, post-event celebrations, social gatherings, and official reception invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the reception invitation letter
- **Joyful Confetti Celebration**: Beautiful confetti burst appears when the invitation is opened
- **Ceremonial Petal Animation**: Soft falling petals create a warm and graceful reception atmosphere
- **Premium Reception Card Layout**: A refined card-style document designed for formal and family reception events
- **Festive Background Animation**: Floating orbs, sparkles, and ceremonial visual elements create a happy celebration feel
- **Royal Reception Styling**: Professional design with a warm, graceful, and joyful reception invitation atmosphere
- **Floating Decorative Icons**: Soft floral and celebration symbols enhance the invitation experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for reception attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender, family, or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the reception occasion
   - Customize reception name, date, time, venue, host, dress code, and RSVP details
   - Update reception highlights according to the actual event schedule
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Family Name / Organization Name" with your actual name, family name, or organization
   - Mention the exact reception ceremony or celebration being organized
   - Add the name of the couple, family, guest of honor, or person being honored
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better hospitality and seating arrangements
   - Mention dress code, reception timing, dinner timing, program schedule, or special instructions if required
   - Customize the tone depending on whether the reception is wedding-related, family-based, formal, corporate, or social

## 🛠️ Customization Guide

### Updating Sender Information

```html

    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Family Name / Organization Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Designation / Relation / Organization<br>
        Address Line<br>
        City, State, PIN Code
    </p>
</div>
```

### Modifying Reception Subject

```text

```

```text

Honoring: [Mention Name / Couple Name / Family Name]

Time: [Mention Start Time]
Venue: [Mention Venue / Banquet / Hall / Location]
Dress Code: [Mention Dress Code, if any]
```
