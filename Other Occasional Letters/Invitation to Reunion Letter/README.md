# 📸 Invitation to Reunion Letter

A warm, nostalgic, and premium reunion invitation letter with animated envelope opening, memory-inspired visuals, joyful confetti effects, and a refined reunion-card presentation.

## 🏢 Overview

This interactive invitation to reunion letter features a heartfelt envelope-to-invitation experience designed to make the recipient feel remembered, valued, and excited to reconnect. The template includes a nostalgic animated background, photo-frame inspired decorative elements, elegant reunion card layout, premium typography, memory-style confetti effects, and a warm plum-gold-rose theme perfect for school reunions, college reunions, family reunions, office reunions, batch reunions, alumni meets, friendship gatherings, and old group get-togethers.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the reunion invitation letter
- **Memory Confetti Celebration**: Warm confetti burst appears when the reunion invitation is opened
- **Premium Reunion Card Layout**: A refined card-style document designed for emotional and formal reunion invitations
- **Nostalgic Background Animation**: Floating orbs, sparkles, ribbons, and photo-frame effects create a memory-filled atmosphere
- **Warm Reunion Styling**: Professional design with a nostalgic and joyful invitation mood
- **Floating Decorative Icons**: Soft memory, friendship, and celebration symbols enhance the reunion experience
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical reunion invitation submission
- **RSVP Section**: Dedicated confirmation area for reunion attendance
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or reunion committee information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the reunion type
   - Customize reunion name, date, time, venue, organizer, theme, and RSVP details
   - Update reunion highlights according to the actual program schedule
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Reunion Committee Name" with your actual name or committee name
   - Update contact information with correct phone number and email address
   - Mention the exact reunion type such as school reunion, college reunion, family reunion, or office reunion
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better reunion planning
   - Mention theme, dress code, memory wall, photo session, dinner, or special instructions if required
   - Customize the tone depending on whether the reunion is formal, friendly, emotional, family-based, academic, or corporate
