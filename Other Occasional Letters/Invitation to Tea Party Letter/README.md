# ☕ Invitation to Tea Party Letter

A warm, elegant, and graceful tea party invitation letter with animated envelope opening, soft tea-themed effects, and a refined social invitation presentation.

## 🏢 Overview

This interactive invitation to tea party letter features a charming envelope-to-invitation experience designed to make the recipient feel welcomed, valued, and delighted. The template includes a warm pastel animated background, elegant tea-party card layout, premium typography, floating steam and leaf effects, and a graceful tea-green-cream-latte theme perfect for tea parties, informal gatherings, family get-togethers, social meetings, garden tea parties, office tea gatherings, farewell tea events, and friendly social invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the tea party invitation letter
- **Tea-Themed Visual Effects**: Floating tea leaves, soft steam lines, and gentle floral elements create a warm invitation feel
- **Premium Tea Party Card Layout**: A refined card-style document designed for graceful social gatherings
- **Warm Pastel Background Animation**: Floating orbs, leaves, and steam effects create a calm and welcoming atmosphere
- **Sophisticated Social Styling**: Professional yet friendly design suitable for both formal and informal tea parties
- **Tea Party Details Section**: Dedicated area for date, time, venue, host, occasion, and dress code
- **Tea Party Highlights Section**: Beautiful section for refreshments, conversations, and gathering details
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace host information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the tea party date or occasion
   - Customize date, time, venue, host name, dress code, and RSVP details
   - Update tea party highlights according to the actual refreshments and arrangements
   - Replace contact information and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Host Name" with your actual name or host name
   - Mention the exact tea party date and time
   - Include complete venue details for easy guest navigation
   - Add RSVP date for better arrangement planning
   - Mention menu items, refreshments, dress code, or special instructions if required
   - Customize the tone depending on whether the tea party is formal, friendly, family-based, office-based, or garden-themed

## 🛠️ Customization Guide

### Updating Host Information

```html
<div class="info-box">
    <div class="info-label">From</div>
    <p>
        <strong>Your Name / Host Name</strong><br>
        Your Address<br>
        City, State, PIN Code<br>
        Email: your.email@example.com<br>
        Phone: +91 XXXXX XXXXX
    </p>
</div>
```

### Updating Recipient Information

```html
<div class="info-box right">
    <div class="info-label">To</div>
    <p>
        <strong>Respected Guest / Recipient Name</strong><br>
        Address Line<br>
        City, State, PIN Code<br>
        Contact Details, if required
    </p>
</div>
```

### Modifying Tea Party Subject

```text
Subject: Invitation to Attend a Tea Party on [Mention Date]
```

### Customizing Tea Party Details

```text
Occasion: Tea Party / Social Gathering
Date: [Mention Tea Party Date]
Time: [Mention Start Time]
Venue: [Mention Venue / Home / Garden / Hall]
Host: [Mention Host Name]
Dress Code: [Mention Dress Code, if any]
```

### Updating Tea Party Highlights

```text
Warm welcome and friendly conversations
Refreshing tea, coffee, and light beverages
Snacks, cookies, cakes, or light refreshments
Relaxed social interaction with guests
Memorable moments in a pleasant atmosphere
```

### Updating RSVP Details

```text
Kindly confirm your presence on or before [Mention RSVP Date].
Contact: [Phone Number]
Email: [Email Address]
```
