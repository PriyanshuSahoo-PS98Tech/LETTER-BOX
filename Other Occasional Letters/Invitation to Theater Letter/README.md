# 🎭 Invitation to Theater Letter

An artistic, elegant, and cinematic invitation letter with animated envelope opening, theater-stage effects, spotlight visuals, and a refined ticket-style event presentation.

## 🏢 Overview

This interactive invitation to theater letter features a premium envelope-to-theater-invitation experience designed to make the recipient feel excited, honored, and welcomed to a stage performance. The template includes cinematic curtain backgrounds, moving spotlight effects, golden dust animation, theater-themed decorative elements, ticket-style event details, and a royal red-gold theme perfect for theater plays, drama performances, stage shows, cultural performances, school dramas, college theater events, auditorium shows, and formal theater invitations.

## ✨ Features

- **Elegant Envelope Animation**: Click to open a premium animated envelope and reveal the theater invitation letter
- **Cinematic Theater Background**: Velvet curtain visuals, spotlight effects, and golden stage atmosphere
- **Applause Celebration Effects**: Theater-themed floating icons appear when the invitation is opened
- **Ticket-Style Event Details**: Dedicated ticket-panel section for performance name, date, time, venue, and entry details
- **Premium Theater Card Layout**: Refined card-style document with theatrical borders and stage-inspired elements
- **Floating Decorative Icons**: Theater masks, tickets, stars, and applause symbols enhance the theme
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical invitation submission
- **RSVP Section**: Dedicated confirmation area for attendance, ticket details, and seating arrangements
- **Keyboard Navigation**: Accessible opening through mouse click, Enter key, or Space key

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file as `index.html` and open it in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender or organization information in the “From” section
   - Update recipient details in the “To” section
   - Modify the subject line according to the theater performance name
   - Customize performance name, date, show time, venue, theater group, and seating details
   - Update performance highlights according to the actual theater program
   - Replace contact information, RSVP details, ticket details, and attachment details as required

3. **Personalization Tips**:
   - Replace "Your Name / Organization Name" with your actual name or organization
   - Mention the exact theater play, drama, act, stage show, or performance name
   - Include complete venue or auditorium details for easy navigation
   - Add seating, ticket, or entry pass information if required
   - Mention RSVP date for better seating and hospitality arrangements
   - Customize the tone depending on whether the invitation is for a school drama, college theater, professional play, cultural performance, or private stage event
