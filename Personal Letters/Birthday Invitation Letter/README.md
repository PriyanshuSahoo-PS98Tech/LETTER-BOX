# 🎂 Birthday Invitation Letter

A vibrant and interactive birthday invitation letter with celebratory envelope animation and colorful confetti effects.

## 🎉 Overview

This interactive birthday invitation letter features a joyful envelope-to-message experience designed to create excitement for the upcoming celebration. The invitation includes floating balloons, confetti animations, and a festive party theme perfect for inviting guests to a birthday bash.

## ✨ Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the invitation
- **Colorful Confetti Effects**: Beautiful falling confetti throughout the experience
- **Floating Balloon Animation**: Gentle balloon animations in the background
- **Festive Typography**: Playful fonts for a celebratory feel
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive RSVP Buttons**: "Count Me In!" and "Maybe" response options
- **Celebration Effects**: Special animations for confirmed attendance
- **No Back Navigation**: One-way journey for maximum impact

## 🎨 Design Elements

### Color Palette
- **Primary**: Purple-blue gradient (#667eea to #764ba2)
- **Accent**: Bright yellow (#ffc107) and coral red (#ff6b6b)
- **Background**: Soft gradients with white overlays
- **Text**: Purple for headings, charcoal for body text

### Typography
- **Main Title**: Fredoka One (playful)
- **Headings**: Dancing Script (cursive)
- **Body Text**: Poppins (sans-serif)
- **Decorative**: Playfair Display (serif)

### Animations
- Envelope opening with flip animation
- Colorful confetti falling effects
- Floating balloons background
- Smooth slide-in content transitions
- Interactive button responses
- Extra celebration confetti for RSVP confirmations

## 📱 Technical Specifications

- **HTML5**: Semantic markup with accessibility considerations
- **CSS3**: Modern flexbox and grid layouts, custom animations
- **JavaScript**: Vanilla JS for interactivity and effects
- **Responsive**: Mobile-first responsive design
- **Browser Support**: Chrome 60+, Firefox 60+, Safari 12+, Edge 79+

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Change the birthday person's name and age
   - Modify the event details (date, time, venue)
   - Update the host name in the signature section
   - Adjust the theme or dress code information

3. **Personalization Tips**:
   - Replace "Sarah Johnson" with the birthday person's name
   - Update the age badge with the correct number
   - Customize the venue and address details
   - Add specific party theme or activities

## 🎈 Content Structure

The birthday invitation includes:
