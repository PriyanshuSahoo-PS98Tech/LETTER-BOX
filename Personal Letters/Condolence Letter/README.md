# 🕊️ Condolence Letter

A respectful and comforting condolence letter with gentle envelope animation and peaceful particle effects.

## 🤍 Overview

This interactive condolence letter features a thoughtful envelope-to-message experience designed to offer comfort and support during times of grief. The letter includes peaceful floating elements, gentle particle animations, and a serene theme perfect for expressing sympathy and honoring the memory of loved ones.

## ✨ Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the condolence message
- **Peaceful Particle Effects**: Gentle drifting particles throughout the experience
- **Floating Serene Elements**: Dove, heart, and leaf animations in the background
- **Respectful Typography**: Dignified fonts that convey sympathy and comfort
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive Response Buttons**: "Thank You" and "Share Memories" options
- **Memorial Sections**: Dedicated areas for comfort and cherished memories
- **No Back Navigation**: One-way journey for complete emotional expression

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace [Name] with the deceased person's actual name
   - Change the sender's name in the signature section
   - Modify the memories list with specific personal details
   - Update the comfort message based on your relationship

3. **Personalization Tips**:
   - Replace "Sarah" with your actual name
   - Add specific memories of the deceased person
   - Include personal references to their character or impact
   - Customize the support offer based on what you can provide
