# 👋 Farewell Letter

A heartfelt and bittersweet farewell letter with gentle envelope animation and drifting memory leaf effects.

## 🌅 Overview

This interactive farewell letter features a thoughtful envelope-to-message experience designed to express gratitude and well-wishes when parting ways. The letter includes floating memory elements, drifting leaf animations, and a warm yet melancholic theme perfect for saying goodbye to colleagues, friends, or loved ones while celebrating shared experiences.

## ✨ Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the farewell message
- **Drifting Leaf Effects**: Gentle memory leaves throughout the experience
- **Floating Memory Elements**: Camera, sunrise, star, and theater mask animations in the background
- **Reflective Typography**: Thoughtful fonts that convey both gratitude and gentle sadness
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive Response Buttons**: "Thank You!" and "Stay Connected!" options
- **Memory Sections**: Dedicated areas for reflection and future wishes
- **No Back Navigation**: One-way journey for complete emotional expression

## 🎨 Design Elements

### Color Palette
- **Primary**: Warm autumn gradient (#ff9a8b to #ffaaa5)
- **Accent**: Earthy brown (#cd853f) and sage green (#a8e6cf)
- **Background**: Soft pastels with cream overlays for nostalgic themes
- **Text**: Warm browns and gentle grays for reflection

### Typography
- **Main Title**: Merriweather (elegant serif)
- **Headings**: Caveat (friendly script)
- **Subheadings**: Dancing Script (flowing cursive)
- **Signature**: Indie Flower (personal handwriting)
- **Body Text**: Poppins (clear sans-serif)

### Animations
- Envelope opening with thoughtful animation
- Drifting leaf effects throughout
- Floating memory background elements
- Smooth slide-in content transitions
- Interactive button responses with appropriate feedback
- Memory effects for emotional responses

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Change the sender's name in the signature section
   - Modify the farewell content to match your situation
   - Update the wishes list with relevant hopes for their future
   - Adjust the reflection section based on your shared experiences

3. **Personalization Tips**:
   - Replace "Taylor" with your actual name
   - Customize the farewell text with specific memories or experiences
   - Add personal references to your time together
   - Include specific achievements or moments you shared
