# 🎭 Invitation Letter (General)

An elegant and versatile invitation letter with sophisticated envelope animation and celebratory sparkle effects.

## 🌟 Overview

This interactive general invitation letter features a refined envelope-to-message experience designed for various types of celebrations and gatherings. The letter includes floating celebration elements, sparkling animations, and an elegant theme perfect for formal events, parties, ceremonies, and special occasions that require a touch of sophistication.

## ✨ Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the invitation
- **Celebratory Sparkle Effects**: Elegant sparkles throughout the experience
- **Floating Celebration Elements**: Confetti, stars, and sparkle animations in the background
- **Sophisticated Typography**: Elegant fonts that convey refinement and importance
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive Response Buttons**: "Count Me In!" and "Can't Make It" options
- **Detailed Event Information**: Organized sections for all event specifics
- **No Back Navigation**: One-way journey for complete invitation experience

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Change the event details in the details grid section
   - Modify the invitation content to match your specific event
   - Update the special notes list with relevant information
   - Adjust the sender name in the signature section

3. **Personalization Tips**:
   - Replace "The Celebration Committee" with your actual name or organization
   - Customize the event type and description
   - Add specific venue details and directions if needed
   - Include any special requirements or requests for guests
