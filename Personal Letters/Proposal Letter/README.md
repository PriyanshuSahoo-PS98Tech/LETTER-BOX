# 💍 Marriage Proposal Letter

A beautifully crafted, interactive marriage proposal letter with romantic envelope animation and rose petal effects.

## 🌹 Overview

This interactive marriage proposal letter features a romantic envelope-to-message experience designed to create an unforgettable moment. The letter includes floating hearts, rose petal animations, and an elegant romantic theme perfect for popping the question.

## ✨ Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the proposal
- **Romantic Rose Petal Effects**: Beautiful falling petals throughout the experience
- **Floating Hearts Animation**: Gentle heart animations in the background
- **Elegant Typography**: Beautiful script fonts for a romantic feel
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive Response Buttons**: "Yes!" and "I need time" options
- **Celebration Effects**: Special animations for positive responses
- **No Back Navigation**: One-way journey for maximum impact

## 🎨 Design Elements

### Color Palette
- **Primary**: Pink gradient (#ff9a9e to #fecfef)
- **Accent**: Deep pink (#ff69b4) and dark red (#8b0000)
- **Background**: Soft pink gradients with white overlays
- **Text**: Dark red for headings, charcoal for body text

### Typography
- **Main Title**: Great Vibes (cursive)
- **Headings**: Dancing Script (cursive)
- **Body Text**: Poppins (sans-serif)
- **Decorative**: Playfair Display (serif)

### Animations
- Envelope opening with flip animation
- Rose petal falling effects
- Floating hearts background
- Smooth slide-in content transitions
- Interactive button responses
- Celebration confetti for "Yes" responses

## 📱 Technical Specifications

- **HTML5**: Semantic markup with accessibility considerations
- **CSS3**: Modern flexbox and grid layouts, custom animations
- **JavaScript**: Vanilla JS for interactivity and effects
- **Responsive**: Mobile-first responsive design
- **Browser Support**: Chrome 60+, Firefox 60+, Safari 12+, Edge 79+

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Change the proposer's name in the signature section
   - Modify the proposal text to make it personal
   - Update the date to your special day
   - Adjust colors in the CSS variables if desired

3. **Personalization Tips**:
   - Replace "Alex" with your name
   - Add specific memories or inside jokes
   - Include references to your relationship journey
   - Customize the ring emoji or add a real photo
