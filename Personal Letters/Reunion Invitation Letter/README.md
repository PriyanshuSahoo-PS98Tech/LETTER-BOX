# 🎓 Reunion Invitation Letter

A nostalgic and heartwarming reunion invitation letter with memory-filled envelope animation and floating bubble effects.

## ✨ Overview

This interactive reunion invitation letter features a thoughtful envelope-to-message experience designed to reconnect classmates, colleagues, or family members for special reunion gatherings. The letter includes floating memory elements, nostalgic bubble animations, and a warm theme perfect for celebrating shared history and rekindling old friendships.

## 🌟 Features

- **Interactive Envelope Animation**: Click to open the envelope and reveal the reunion invitation
- **Memory Bubble Effects**: Gentle floating bubbles throughout the experience
- **Floating Memory Elements**: Books, celebration, people, and star animations in the background
- **Nostalgic Typography**: Warm fonts that evoke feelings of reminiscence and connection
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive Response Buttons**: "Count Me In!" and "Still Deciding" options
- **Detailed Event Information**: Organized sections for all reunion specifics
- **No Back Navigation**: One-way journey for complete invitation experience

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Change the graduation year and class details
   - Modify the reunion event specifics (date, venue, cost)
   - Update the activities list with planned events
   - Adjust the organizing committee name in the signature

3. **Personalization Tips**:
   - Replace "Class of 2014" with your actual graduation year
   - Customize the venue and location details
   - Add specific school or organization references
   - Include any special themes or dress code requirements
