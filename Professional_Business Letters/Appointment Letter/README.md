# 🧾 Appointment Letter

A professional and sophisticated appointment letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive appointment letter features a corporate-standard envelope-to-document experience designed for formal employment appointments and official HR communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated indigo-blue theme perfect for employee appointment letters, internship appointments, contractual hiring, HR onboarding, corporate joining communication, and official employment confirmation.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal appointment letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey authority, trust, and clarity
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission and HR records
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace company/organization information in the header section
   - Update candidate details with actual employee information
   - Modify the subject line according to the appointed position
   - Customize appointment details such as job title, department, joining date, and work location
   - Replace HR details, reporting manager name, and company terms throughout the letter

3. **Personalization Tips**:
   - Replace "Company / Organization Name" with the actual company name
   - Replace "Candidate Full Name" with the selected candidate's name
   - Update the appointment position, department, and joining date accurately
   - Mention the correct work location, reporting manager, and employment type
   - Add salary, benefits, and probation details if required
   - Include document submission requirements as per company policy

## 💼 Content Structure

The appointment letter includes:
- **Professional header** with complete company information
- **Formal date** and candidate addressing
- **Clear subject line** specifying the appointed position
- **Professional salutation** with proper HR etiquette
- **Opening paragraph** confirming the candidate’s appointment
- **Appointment details section** highlighting job role, department, joining date, and reporting manager
- **Document submission paragraph** explaining joining formalities
- **Terms and conditions section** outlining employment expectations and company policies
- **Probation and confirmation paragraph** explaining employment review process
- **Acceptance section** requesting signed confirmation from the candidate
- **Formal signature** with authorized signatory details
- **Enclosures list** for required joining documents

## 🛠️ Customization Guide

### Updating Company Information

```html
<div class="company-info">
    <strong>Company / Organization Name</strong><br>
    Registered Office Address<br>
    City, State, PIN Code<br>
    Email: hr@company.com<br>
    Phone: +91 XXXXX XXXXX
</div>
```

### Modifying Appointment Subject

```text
Subject: Appointment Letter for the Position of [Job Title]
```

### Customizing Appointment Details

```text
Position: [Job Title]
Department: [Department Name]
Date of Joining: [Joining Date]
Work Location: [Office / Branch Location]
Reporting Manager: [Manager Name / Designation]
Employment Type: [Full-Time / Part-Time / Contract / Internship]
Probation Period: [Mention Duration, if applicable]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)

Print styles automatically optimize the layout for professional appointment submission and HR documentation.
