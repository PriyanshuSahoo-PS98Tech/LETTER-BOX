# ⚖️ Demand Letter

A professional and sophisticated demand letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive demand letter features a corporate-standard envelope-to-document experience designed for formal payment demands, settlement requests, pending dues, refund demands, compliance requests, and official resolution communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated indigo-blue theme perfect for serious business communication and formal demand notices.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal demand letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey seriousness and authority
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace sender contact information in the header section
   - Update recipient details with actual person/company information
   - Modify the subject line according to the demand purpose
   - Customize reference number, due date, amount, and required action
   - Replace agreement, invoice, transaction, or service details throughout the letter

3. **Personalization Tips**:
   - Replace "Your Full Name / Company Name" with your actual name or business name
   - Update contact information with correct professional details
   - Mention invoice number, agreement date, or transaction reference if applicable
   - Clearly specify the outstanding amount or required action
   - Add a reasonable deadline for response or payment
   - Attach proof such as invoice, receipt, agreement, or previous communication records

## 💼 Content Structure

The demand letter includes:
- **Professional header** with complete sender information
- **Formal date** and recipient addressing
- **Clear subject line** specifying the demand purpose
- **Professional salutation** with proper business etiquette
- **Opening paragraph** stating the demand formally
- **Due amount/details paragraph** explaining the pending matter
- **Demand details section** highlighting reference number, amount, due date, and required action
- **Final request and deadline section** specifying the response period
- **Consequence paragraph** explaining possible further action
- **Formal signature** with contact details
- **Enclosures/reference section** for supporting documents

## 🛠️ Customization Guide

### Updating Sender Information

```html
<div class="sender-info">
    <strong>Your Full Name / Company Name</strong><br>
    Your Address<br>
    City, State, PIN Code<br>
    Email: your.email@example.com<br>
    Phone: +91 XXXXX XXXXX
</div>
```

### Modifying Demand Subject

```text
Subject: Formal Demand for [Payment / Refund / Resolution / Compliance]
```

### Customizing Demand Details

```text
Reference Number / Invoice Number: [Mention Reference]
Original Due Date: [Mention Due Date]
Outstanding Amount: ₹[Mention Amount]
Required Action: [Payment / Replacement / Refund / Compliance / Resolution]
Deadline: [Mention Number of Days]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)

Print styles automatically optimize the layout for professional demand submission.
