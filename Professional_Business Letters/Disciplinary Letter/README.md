# ⚠️ Disciplinary Letter

A professional and sophisticated disciplinary letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive disciplinary letter features a corporate-standard envelope-to-document experience designed for formal workplace notices, employee conduct communication, and official disciplinary documentation. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated charcoal-red theme perfect for employee warnings, policy violation notices, misconduct communication, performance concerns, and HR disciplinary records.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal disciplinary letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for HR and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey seriousness and authority
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for official HR documentation
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace company/institution information in the header section
   - Update employee details with actual employee information
   - Modify the subject line according to the disciplinary matter
   - Customize incident details, policy references, and corrective actions
   - Replace HR manager, reporting manager, and department details throughout the letter

3. **Personalization Tips**:
   - Replace "Employee Full Name" with the actual employee name
   - Update employee ID, designation, department, and work location
   - Mention the exact incident date, time, and location
   - Clearly describe the issue in a factual and professional tone
   - Add policy references or previous warning details if applicable
   - Specify the deadline for written explanation or corrective action

## 🛠️ Customization Guide

### Updating Company Information

```html
<div class="company-info">
    <strong>Company / Institution Name</strong><br>
    Human Resources Department<br>
    Company Address<br>
    City, State, PIN Code<br>
    Email: hr@company.com
</div>
```

### Modifying Disciplinary Subject

```text
Subject: Disciplinary Notice Regarding [Workplace Conduct / Policy Violation / Performance Issue]
```

### Customizing Incident Details

```text
Date of incident: [Mention Date]
Nature of issue: [Misconduct / Absenteeism / Policy Violation / Poor Performance]
Policy violated: [Mention Policy / Rule]
Required action: [Written Explanation / Meeting / Corrective Improvement]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)

Print styles automatically optimize the layout for professional HR documentation.
