# 📄 Layoff Letter

A professional and sophisticated layoff letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive layoff letter features a corporate-standard envelope-to-document experience designed for formal employment separation communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated slate-gray theme perfect for workforce reduction notices, position elimination letters, restructuring communication, HR documentation, and professional employee transition notices.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal layoff letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for HR and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain seriousness and professionalism
- **Corporate Typography**: Professional fonts that convey clarity, respect, and sensitivity
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for official HR documentation
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace company and HR contact information in the header section
   - Update employee details including name, employee ID, designation, and department
   - Modify the subject line according to the separation purpose
   - Customize last working date, final settlement date, and severance details
   - Replace company name and policy-related details throughout the letter

3. **Personalization Tips**:
   - Replace "Company Name" with the actual organization name
   - Update employee name and employment details accurately
   - Mention the correct last working date
   - Include severance, notice pay, or benefits details only if applicable
   - Add HR contact details for employee support
   - Review the letter according to company policy and applicable labor laws before use

## 💼 Content Structure

The layoff letter includes:
- **Professional header** with complete company and HR information
- **Formal date** and employee addressing
- **Clear subject line** specifying position elimination notice
- **Professional salutation** with respectful tone
- **Opening paragraph** communicating the layoff decision formally
- **Reason paragraph** explaining restructuring or business requirement
- **Employment separation details section** listing key dates and settlement information
- **Support and assistance section** explaining HR support availability
- **Handover paragraph** requesting return of company property
- **Appreciation paragraph** acknowledging employee contribution
- **Formal signature** with HR representative details
- **Copy distribution section** for official HR documentation

### Modifying Layoff Subject

```text
Subject: Notice of Position Elimination
```

### Customizing Separation Details

```text
Last working date: [Mention Date]
Final salary settlement date: [Mention Date]
Severance package: [Mention Details if applicable]
Notice period payment: [Mention Details]
Benefits continuation: [Mention Duration / Terms]
Company property return deadline: [Mention Date]
```
