# 📢 Notice Letter

A professional and sophisticated notice letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive notice letter features a corporate-standard envelope-to-document experience designed for formal announcements and official communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated indigo-blue theme perfect for institutional notices, office announcements, meeting notices, event notifications, administrative updates, and official circular-style communication.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal notice letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and institutional environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey authority and clarity
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical notice board display
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace organization/institution information in the header section
   - Update the date according to the notice issue date
   - Modify the subject line according to the notice purpose
   - Customize notice details such as topic, date, time, venue, and applicability
   - Replace authority designation and department details throughout the letter

3. **Personalization Tips**:
   - Replace "Organization / Institution Name" with the actual name
   - Update official address, email, and phone number
   - Mention the exact topic of the notice
   - Clearly specify date, time, venue, and target audience
   - Add reference number if required
   - Include important instructions and contact information for clarification

## 🛠️ Customization Guide

### Updating Organization Information

```html
<div class="organization-info">
    <h2>Organization / Institution Name</h2>
    <p>Address Line, City, State, PIN Code</p>
    <p>Email: official@example.com | Phone: +91 XXXXX XXXXX</p>
</div>
```

### Modifying Notice Subject

```text
Subject: Important Notice Regarding [Meeting / Event / Announcement]
```

### Customizing Notice Details

```text
Topic: [Mention Meeting / Event / Announcement Topic]
Date: [Mention Date]
Time: [Mention Time]
Venue: [Mention Venue / Online Meeting Link]
Applicable To: [Students / Employees / Members / Department]
Reference No.: [Notice Reference Number, if any]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)

Print styles automatically optimize the layout for professional notice display or official submission.
