# 🛒 Order Letter

A professional and sophisticated order letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive order letter features a corporate-standard envelope-to-document experience designed for formal purchase orders and professional business procurement communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated amber-brown theme perfect for product orders, bulk purchase requests, supplier communication, business procurement, catalogue-based orders, and official order placement.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal order letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey clarity and reliability
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace buyer/sender contact information in the header section
   - Update supplier/vendor details with actual business information
   - Modify the subject line according to the order purpose
   - Customize item names, quantity, rate, delivery address, and payment terms
   - Replace company name and order reference details throughout the letter

3. **Personalization Tips**:
   - Replace "Your Full Name / Company Name" with your actual name or business name
   - Update contact information with correct professional details
   - Mention order number, quotation reference, or catalogue reference if applicable
   - Clearly specify item name, model, quantity, rate, and total amount
   - Add delivery deadline, shipping address, and payment method
   - Request order confirmation and invoice copy from the supplier

## 💼 Content Structure

The order letter includes:
- **Professional header** with complete buyer/sender information
- **Formal date** and supplier/vendor addressing
- **Clear subject line** specifying the order purpose
- **Professional salutation** with proper business etiquette
- **Opening paragraph** placing the order formally
- **Order details section** highlighting item names, quantity, rate, and total amount
- **Delivery instructions section** explaining shipping address and deadline
- **Payment terms section** specifying payment mode and billing details
- **Confirmation paragraph** requesting acknowledgement and invoice
- **Formal signature** with contact details
- **Reference/attachment section** for quotation, catalogue, or purchase order details

```text

```

### Customizing Order Details

```text

Item Name: [Mention Product Name]
Quantity: [Mention Quantity]
Rate: [Mention Price Per Unit]
Delivery Address: [Mention Full Address]

```
