# 🏠 Rental Letter

A professional and sophisticated rental letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive rental letter features a corporate-standard envelope-to-document experience designed for formal rental communication and property accommodation requests. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated slate-gray theme perfect for rental applications, property enquiries, lease confirmations, accommodation requests, landlord communication, and rental agreement formalities.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal rental letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and property-related communication
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey clarity and responsibility
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace tenant/sender contact information in the header section
   - Update landlord or property manager details with actual information
   - Modify the subject line according to the rental purpose
   - Customize property address, rent amount, deposit, and move-in date
   - Replace rental terms and document requirements throughout the letter

3. **Personalization Tips**:
   - Replace "Your Full Name" with your actual full name
   - Update contact information with your correct details
   - Mention the exact property address and property type
   - Clearly specify rent amount, security deposit, and rental duration
   - Add preferred move-in date and payment method if applicable
   - Attach identity proof, address proof, and previous rental reference if required

## 💼 Content Structure

The rental letter includes:
- **Professional header** with complete tenant/sender information
- **Formal date** and landlord/property manager addressing
- **Clear subject line** specifying the rental purpose
- **Professional salutation** with proper business etiquette
- **Opening paragraph** introducing the rental request formally
- **Property details section** highlighting address, rent, deposit, and duration
- **Rental terms section** requesting agreement, charges, rules, and receipts
- **Assurance paragraph** confirming responsible property usage
- **Closing paragraph** requesting confirmation and next steps
- **Formal signature** with contact details
- **Reference/attachment section** for proof documents
