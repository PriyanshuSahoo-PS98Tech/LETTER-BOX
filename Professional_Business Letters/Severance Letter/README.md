# 📄 Severance Letter

A professional and sophisticated severance letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive severance letter features a corporate-standard envelope-to-document experience designed for formal employment separation communication. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated indigo-blue theme perfect for severance notices, employment separation letters, HR documentation, final settlement communication, and professional exit procedures.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal severance letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for HR and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey seriousness and respect
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for HR documentation
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace company and HR contact information in the header section
   - Update employee details with actual employee information
   - Modify the subject line according to the severance purpose
   - Customize severance amount, final settlement, benefits, and exit terms
   - Replace company name and HR representative details throughout the letter

3. **Personalization Tips**:
   - Replace "Company Name" with the actual organization name
   - Update employee name, employee ID, position, and department
   - Mention the effective separation date and last working day
   - Clearly define severance amount, final salary, and leave encashment details
   - Add company property return instructions and deadlines
   - Include acknowledgement requirements and HR contact details

## 💼 Content Structure

The severance letter includes:
- **Professional header** with complete company/HR information
- **Formal date** and employee addressing
- **Clear subject line** specifying severance and separation notice

