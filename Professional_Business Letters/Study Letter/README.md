# 📚 Study Letter

A professional and sophisticated study letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive study letter features a corporate-standard envelope-to-document experience designed for formal academic communication and educational requests. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated indigo-purple theme perfect for study permission requests, academic support letters, study leave applications, further study requests, student documentation, and official communication with schools, colleges, institutions, or universities.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal study letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for academic and institutional environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey academic seriousness and clarity
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace student contact information in the header section
   - Update institution, principal, or department details
   - Modify the subject line according to the study purpose
   - Customize course, class, roll number, and academic details
   - Replace study reason, duration, and required support throughout the letter

3. **Personalization Tips**:
   - Replace "Your Full Name" with your actual full name
   - Update student ID, roll number, course, and department details
   - Mention the exact purpose of the study letter
   - Clearly explain whether it is for study leave, permission, further study, or academic support
   - Add duration, subject, study plan, or academic requirement if applicable
   - Attach student ID, academic records, or supporting documents when needed

## 💼 Content Structure

The study letter includes:
- **Professional header** with complete student information
- **Formal date** and institution/authority addressing
- **Clear subject line** specifying the study purpose
- **Professional salutation** with proper academic etiquette
- **Opening paragraph** introducing the academic request formally
- **Study details section** highlighting student and academic information
- **Purpose paragraph** explaining the study requirement
- **Formal request section** asking for permission, support, or approval
- **Assurance paragraph** confirming responsibility and discipline
- **Formal signature** with student contact details
- **Enclosures list** for academic supporting documents

## 🛠️ Customization Guide

### Updating Student Information

```html
<div class="sender-info">
    <strong>Your Full Name</strong><br>
    Student ID / Roll Number: [ID Number]<br>
    Department / Class: [Department or Class Name]<br>
    Institution Name<br>
    Email: your.email@example.com<br>
    Phone: +91 XXXXX XXXXX
</div>
```

### Modifying Study Subject

```text
Subject: Request for Permission / Support for [Study Purpose]
```

### Customizing Study Details

```text
Student Name: [Your Full Name]
Course/Class: [Mention Course or Class]
Roll Number / Student ID: [Mention ID]
Subject / Area of Study: [Mention Subject]
Purpose: [Further Study / Extra Classes / Study Leave / Academic Support]
Required Duration: [Mention Duration if applicable]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)

Print styles automatically optimize the layout for professional academic submission.
