# ⚠️ Warning Letter

A professional and sophisticated warning letter with enterprise-grade envelope animation and refined document presentation.

## 🏢 Overview

This interactive warning letter features a corporate-standard envelope-to-document experience designed for formal disciplinary communication and official warning notices. The letter includes subtle professional animations, enterprise-grade styling, and a sophisticated red-orange theme perfect for employee warnings, student warnings, workplace misconduct notices, performance improvement warnings, policy violation notices, and formal disciplinary documentation.

## ✨ Features

- **Professional Envelope Animation**: Click to open the envelope and reveal the formal warning letter
- **Enterprise-Grade Styling**: Sophisticated design suitable for official and corporate environments
- **Floating Professional Elements**: Subtle background animations that maintain professionalism
- **Corporate Typography**: Professional fonts that convey seriousness and authority
- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Print-Optimized**: Professional print styles for physical submission
- **No Interactive Elements**: Pure document presentation without casual response buttons
- **Keyboard Navigation**: Professional accessibility features for enterprise use

## 🚀 Usage Instructions

1. **Setup**: Save the HTML file and open in any modern web browser
2. **Customization**: Edit the content in the HTML file:
   - Replace company/institution information in the header section
   - Update employee/student/recipient details with actual information
   - Modify the subject line according to the warning reason
   - Customize incident date, misconduct details, policy violation, and corrective actions
   - Replace department, authority, and record details throughout the letter

3. **Personalization Tips**:
   - Replace "Employee / Recipient Name" with the actual name
   - Update employee ID, roll number, designation, or department details
   - Mention the exact incident date and nature of the issue
   - Keep the warning language professional, clear, and respectful
   - Add previous verbal or written reminders if applicable
   - Clearly mention expected corrective action and future consequences

## 💼 Content Structure

The warning letter includes:
- **Professional header** with complete company/institution information
- **Formal date** and recipient details
- **Clear subject line** specifying the warning purpose

- **Opening paragraph** stating the formal warning
- **Details of concern section** highlighting incident and violation information
- **Corrective action section** explaining expected improvement
- **Consequence paragraph** mentioning possible disciplinary action

## 🛠️ Customization Guide

### Updating Company / Institution Information

```html
<div class="company-info">
    <strong>Company / Institution Name</strong><br>
    Human Resources Department<br>
    Company Address<br>
    City, State, PIN Code<br>
    Email: hr@company.com
</div>
```

### Modifying Warning Subject

```text
Subject: Formal Warning Regarding [Misconduct / Policy Violation / Poor Performance]
```

### Customizing Warning Details

```text
Date of incident: [Mention Date]
Nature of issue: [Mention Misconduct / Violation / Performance Issue]
Policy or rule affected: [Mention Applicable Rule]
Expected action: [Mention Required Improvement]
```

### Print Functionality

Use:

* **Ctrl + P** (Windows)
* **Cmd + P** (Mac)
