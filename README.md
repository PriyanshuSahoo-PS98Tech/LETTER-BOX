## 📖 About The Project

**LETTER BOX** is a beautifully designed web-based letter template project created to bring back the warmth, emotion, and personal touch of traditional letters in a modern digital format.

In earlier times, people used to write letters on paper to express their feelings, emotions, loneliness, happiness, apologies, love, gratitude, respect, invitations, blessings, memories, and important life messages. Those handwritten letters carried a special value because every word felt personal and meaningful.

Keeping that same emotion in mind, **LETTER BOX** was created as a digital experience using modern web technologies.

We know that letters written on paper will always feel more special, personal, and timeless. Nothing can completely replace the beauty of a handwritten letter. But through this project, we have tried our best to make digital letters feel beautiful, emotional, memorable, and close to the heart.

**LETTER BOX** is not just a collection of templates.  
It is a digital letter experience designed for almost every situation of life.

---

## 📮 Why LETTER BOX?

The name **LETTER BOX** is inspired by the old and meaningful tradition of sending and receiving letters.

A letter box was once a place where emotions waited silently — a place where people dropped messages filled with love, apologies, blessings, invitations, hope, memories, gratitude, and life-changing words.

A letter was never just a piece of paper.  
It carried feelings, time, effort, memories, and personal connection.

We chose the name **LETTER BOX** because this project follows the same emotional idea.

Instead of physical paper and envelopes, this project uses digital envelopes, animations, modern layouts, colors, and carefully written content to create a special experience for the reader.

**LETTER BOX** represents:

- 📮 A modern digital post box
- 💌 A place for emotions
- 📝 A collection of meaningful writings
- 🎁 A digital gift for someone special
- 🌐 A modern version of traditional paper letters
- ❤️ A template library for every meaningful situation
- ✨ A creative blend of words, design, and technology

Even though digital letters cannot completely replace handwritten letters, this project tries to preserve the beauty of letters in a modern, interactive, and professional way.

## 🎨 Customization Guide

Each letter template can be customized by editing the following files:

* `index.html` for text and structure
* `style.css` for colors, fonts, layout, and animation
* `script.js` for interaction, effects, password logic, and optional music

### Change Letter Content

Open `index.html` and update the text inside the letter content section.

```html
<p class="paragraph">
  Write your customized letter message here.
</p>
```

### Change Envelope Text

Find the envelope instruction text in `index.html`.

```html
<p class="open-text">Open this letter</p>
```

Update it as needed.

```html
<p class="open-text">Open Your Special Message</p>
```

### Change Theme Colors

Open `style.css` and update the color variables or gradient values.

```css
:root {
    --primary-color: #1e3a8a;
    --secondary-color: #2563eb;
    --accent-color: #67e8f9;
    --paper-color: #f8fafc;
}
```

### Change Fonts

Update the Google Fonts link in `index.html`.

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Playfair+Display:wght@600;700&display=swap" rel="stylesheet">
```

Then apply the font in `style.css`.

```css
body {
    font-family: 'Inter', sans-serif;
}

.main-title {
    font-family: 'Playfair Display', serif;
}
```

## 🎵 Add Background Music When Envelope Opens

If you want to play a song when the envelope opens, follow these steps.

### Step 1: Add Audio Tag In `index.html`

Add this before the closing `</body>` tag:

```html
<audio id="backgroundMusic" src="assets/music/background-song.mp3"></audio>
```

Recommended folder structure:

```bash
LETTER-BOX/
│
├── index.html
├── style.css
├── script.js
└── assets/
    └── music/
        └── background-song.mp3
```

### Step 2: Update `script.js`

Find your envelope opening function. It may look like this:

```js
function openLetter() {
    envelope.classList.add("envelope-opening");

    setTimeout(() => {
        envelopeContainer.classList.add("hidden");
    }, 600);

    setTimeout(() => {
        documentBox.classList.add("show");
    }, 800);
}
```

Now update it like this:

```js
function openLetter() {
    const music = document.getElementById("backgroundMusic");

    if (music) {
        music.currentTime = 0;
        music.play().catch((error) => {
            console.log("Music play was blocked by browser:", error);
        });
    }

    envelope.classList.add("envelope-opening");

    setTimeout(() => {
        envelopeContainer.classList.add("hidden");
    }, 600);

    setTimeout(() => {
        documentBox.classList.add("show");
        document.body.style.overflow = "hidden";
    }, 800);
}
```

### Important Note

Modern browsers usually allow music only after a user interaction. Since the user clicks the envelope first, the song should play correctly when the envelope opens.

## 🔐 Add Password Before Opening The Letter

You can add a simple password screen before showing the envelope.

### Step 1: Add Password Screen In `index.html`

Place this inside `<body>` before the envelope container:

```html
<div class="password-screen" id="passwordScreen">
    <div class="password-card">
        <h2>Enter Password</h2>
        <p>Please enter the password to open this letter.</p>

        <input type="password" id="letterPassword" placeholder="Enter password">
        <button onclick="checkPassword()">Unlock Letter</button>

        <p class="error-message" id="passwordError"></p>
    </div>
</div>
```

Add the `locked` class to your envelope container:

```html
<div class="envelope-container locked" id="envelopeContainer">
    <!-- Envelope code here -->
</div>
```

### Step 2: Add CSS In `style.css`

```css
.password-screen {
    position: fixed;
    inset: 0;
    background: linear-gradient(135deg, #111827, #1e3a8a);
    display: flex;
    justify-content: center;
    align-items: center;
    z-index: 9999;
    padding: 20px;
}

.password-card {
    width: 100%;
    max-width: 380px;
    background: rgba(255, 255, 255, 0.12);
    border: 1px solid rgba(255, 255, 255, 0.25);
    border-radius: 24px;
    padding: 32px;
    text-align: center;
    color: white;
    backdrop-filter: blur(16px);
    box-shadow: 0 25px 70px rgba(0, 0, 0, 0.35);
}

.password-card h2 {
    margin-bottom: 12px;
    font-size: 28px;
}

.password-card p {
    margin-bottom: 18px;
    color: rgba(255, 255, 255, 0.8);
}

.password-card input {
    width: 100%;
    padding: 14px 16px;
    border-radius: 14px;
    border: none;
    outline: none;
    margin-bottom: 16px;
    font-size: 15px;
}

.password-card button {
    width: 100%;
    padding: 14px 18px;
    border: none;
    border-radius: 14px;
    background: linear-gradient(135deg, #38bdf8, #6366f1);
    color: white;
    font-weight: 700;
    cursor: pointer;
    transition: 0.3s ease;
}

.password-card button:hover {
    transform: translateY(-2px);
    box-shadow: 0 12px 30px rgba(99, 102, 241, 0.4);
}

.error-message {
    margin-top: 14px;
    color: #fecaca !important;
    font-weight: 600;
}

.envelope-container.locked {
    display: none;
}
```

### Step 3: Add Password Logic In `script.js`

```js
const correctPassword = "letterbox123";

function checkPassword() {
    const inputPassword = document.getElementById("letterPassword").value;
    const passwordScreen = document.getElementById("passwordScreen");
    const envelopeContainer = document.getElementById("envelopeContainer");
    const passwordError = document.getElementById("passwordError");

    if (inputPassword === correctPassword) {
        passwordScreen.style.display = "none";
        envelopeContainer.classList.remove("locked");
    } else {
        passwordError.textContent = "Incorrect password. Please try again.";
    }
}
```

### Change Password Here

```js
const correctPassword = "letterbox123";
```

Replace `letterbox123` with your own password.

### Deploy On Netlify

1. Go to Netlify.
2. Login with GitHub.
3. Click **Add New Site**.
4. Choose **Import an existing project**.
5. Select your GitHub repository.
6. Keep the build command empty for a static HTML project.
7. Set the publish directory to the folder where `index.html` is present.
8. Click **Deploy Site**.

### Deploy On Vercel

1. Go to Vercel.
2. Login with GitHub.
3. Click **Add New Project**.
4. Import your repository.
5. Keep framework preset as **Other** if it is plain HTML/CSS/JS.
6. Click **Deploy**.
